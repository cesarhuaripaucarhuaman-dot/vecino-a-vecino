# Vecino a Vecino (prueba)
1. Instala Node.js 18+ (https://nodejs.org).
2. En esta carpeta: `node server.js`
3. Abre http://localhost:3000
4. Otros celulares en el mismo Wi-Fi: usa la dirección "En tu red" que imprime el servidor.

Prueba offline: pulsa "Probar sin internet", publica algo, vuelve a conectar y verás "Se sincronizaron…".
Prueba multiusuario: abre dos navegadores (o uno en modo incógnito), publica en uno y mira que aparece en el otro en ≤15 s.
Nota: GPS e instalación como app requieren HTTPS o localhost; por IP de red usará la zona de ejemplo.
Los datos compartidos se guardan en data.json.
